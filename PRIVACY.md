# Privacy policy

Last updated: 4 November 2026

K7 is a self-hosted media server. The Android, iOS, and desktop apps are clients for a server you choose. This policy describes what the publisher of those apps does with personal data.

Contact: [contact@kaybi.dev](mailto:contact@kaybi.dev)

## Data the publisher does not collect

The apps do not include advertising, analytics, or crash reporting that sends data to the publisher.

The apps do not send your account, library, playback, downloads, reviews, or SyncPlay messages to the publisher. That data goes to the server address you enter, and it stays there. The publisher cannot see it and cannot delete it. The administrator of that server decides how long it is kept and who can access it.

Use HTTPS on that server when you can. The apps can also connect over plain HTTP if the server does not offer TLS.

## Data stored on the device

The app keeps on the device what it needs to run: the server address, the session, preferences, and files you download. Uninstalling the app or clearing its storage removes that local copy. It does not remove data already stored on the server.

## Optional demo server

[k7.kaybi.dev](https://k7.kaybi.dev) is an optional demo. It is not used unless you choose that address. Only guest login is available there. A guest session on that server is processed by the publisher as the operator of the demo, for the sole purpose of running the demo.

## Other requests

- Google Cast is used only if you start casting. Playback then goes to the Cast device you select.
- Language flags in the player are loaded from flagcdn.com. That request shows your IP address to that host. No account data is sent with it.

## Children

K7 is not directed at children under 13.

## Changes

Updates to this policy are published in this file.

# Politique de confidentialité

Dernière mise à jour : 4 novembre 2026

K7 est un serveur multimédia auto-hébergé. Les applications Android, iOS et desktop sont des clients pour un serveur que vous choisissez. Cette politique décrit ce que l'éditeur de ces applications fait des données personnelles.

Contact : [contact@kaybi.dev](mailto:contact@kaybi.dev)

## Données que l'éditeur ne collecte pas

Les applications n'incluent pas de publicité, de mesure d'audience, ni de rapport de plantage envoyé à l'éditeur.

Les applications n'envoient pas à l'éditeur votre compte, votre bibliothèque, vos lectures, vos téléchargements, vos avis, ni les messages SyncPlay. Ces données vont à l'adresse de serveur que vous saisissez, et elles y restent. L'éditeur ne peut pas les voir et ne peut pas les supprimer. L'administrateur de ce serveur décide de leur durée de conservation et de qui peut y accéder.

Utilisez HTTPS sur ce serveur quand c'est possible. Les applications peuvent aussi se connecter en HTTP simple si le serveur ne propose pas TLS.

## Données stockées sur l'appareil

L'application conserve sur l'appareil ce qui lui sert à fonctionner : l'adresse du serveur, la session, les préférences, et les fichiers que vous téléchargez. Désinstaller l'application ou effacer son stockage supprime cette copie locale. Cela ne supprime pas les données déjà stockées sur le serveur.

## Serveur de démonstration

[k7.kaybi.dev](https://k7.kaybi.dev) est une démonstration facultative. Elle n'est pas utilisée tant que vous ne choisissez pas cette adresse. Seule une connexion invité y est disponible. Une session invité sur ce serveur est traitée par l'éditeur en tant qu'opérateur de la démonstration, dans le seul but de la faire fonctionner.

## Autres requêtes

- Google Cast n'est utilisé que si vous lancez une diffusion. La lecture part alors vers l'appareil Cast que vous sélectionnez.
- Les drapeaux de langue dans le lecteur sont chargés depuis flagcdn.com. Cette requête montre votre adresse IP à cet hébergeur. Aucune donnée de compte n'est envoyée avec.

## Enfants

K7 ne s'adresse pas aux enfants de moins de 13 ans.

## Modifications

Les mises à jour de cette politique sont publiées dans ce fichier.
