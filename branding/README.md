# Branding

Pre-colored SVG copies of the Design System brand variants. Construction source: `logo-build.svg`.

Backgrounds are transparent. Preview dark variants on `#0d0907` and light variants on `#e4e3d9`.

## Logo (wordmark, 128x70)

| File | Design System label | Colors |
|---|---|---|
| `logo.svg` | Brand (white + accent symbol) | cream `#f3ecde` + accent `#d9b060` |
| `logo-on-light.svg` | Brand (black + accent symbol) | ink `#262420` + accent `#c49a48` |
| `logo-white.svg` | White on dark | cream `#f3ecde` |
| `logo-black.svg` | Black on light | ink `#262420` |

`logo.svg` is the default mark.

## Symbol (mark, 38x28)

| File | Design System label | Color |

| `symbol-on-light.svg` | Accent on light | `#c49a48` |
| `symbol-white.svg` | White on dark | cream `#f3ecde` |
| `symbol-black.svg` | Black on light | ink `#262420` |
